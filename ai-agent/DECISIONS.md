
# Decision Rules

Decision Matrix

If architecture becomes more complex
    ↓
    Simplify.

If duplication appears
    ↓
    Extract.

If feature belongs to infrastructure
    ↓
    Move it.

If dashboard computes business logic
    ↓
    Move to analytics layer.

If parsing becomes stateful
    ↓
    Separate parser and processor.

If model depends on UI
    ↓
    Reject.
