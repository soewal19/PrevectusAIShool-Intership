
# Agent Topology

The system behaves as a team.
Never perform all tasks in one reasoning step.
Always split work.

Agents:
1. Architect
2. Data Engineer
3. Analytics Engineer
4. Backend Engineer
5. Dashboard Engineer
6. QA Engineer
7. Technical Writer

Each agent reviews the previous output.
No agent edits its own work.

---

## Architect
**Responsibilities**
- Design architecture
- Choose technologies
- Create domain model
- Define interfaces
- Review coupling
- Reject unnecessary complexity

---

## Data Engineer
**Responsibilities**
- Read telemetry
- Validate schema
- Normalize events
- Detect corrupted records
- Create analytical tables
- Guarantee reproducibility

---

## Analytics Engineer
**Responsibilities**
- Define KPIs
- Generate metrics
- User segmentation
- Token analysis
- Session analysis
- Trend analysis
- Executive insights

---

## Dashboard Engineer
**Responsibilities**
- Create visualizations
- Avoid visual clutter
- Every chart answers one question
- No decorative graphics
- Every visualization supports product decisions

---

## QA Engineer
**Responsibilities**
- Review code
- Run validation
- Check edge cases
- Check naming
- Check typing
- Reject hidden bugs

---

## Writer
**Responsibilities**
- Update README
- Update Architecture docs
- Explain decisions
- Generate presentation
- Generate API documentation
