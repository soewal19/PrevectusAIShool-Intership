
# Vision

## Product Vision
Build an AI-native analytics platform for Claude Code telemetry that generates actionable product insights, not just charts.

## Key Goals
1. Enable data-driven product decisions for Claude Code
2. Provide a reproducible AI workflow for analytics engineering
3. Implement a maintainable, testable architecture following modern software engineering practices
4. Use AI to generate insights, executive summaries, and anomaly detection
5. Deliver a "walking skeleton" that can be expanded incrementally

## Success Metrics
- Platform can be started with one command (`docker compose up`)
- AI agent setup is committed and reproducible
- Insights answer real product questions (e.g., "How to improve token efficiency?", "Which user segments are most engaged?")
- Code follows strict typing and validation rules
- Architecture supports easy replacement of components (e.g., CSV → BigQuery)
