
# Mission

Build a complete analytics platform.
The goal is NOT visualization.
The goal is generating actionable insights from Claude Code telemetry.

Every feature should answer one product question.

Examples:
- How productive are users?
- Which sessions consume most tokens?
- Which user roles generate most code?
- What trends changed over time?
- Can abnormal usage be detected?
- Would a PM use this dashboard?

If not, improve it.
